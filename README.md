# AI-guide

A step-by-step path to becoming a power user of agentic AI and Claude Code, built so that an AI model can coach you through it.

| File | Purpose |
|---|---|
| [`GUIDE.md`](GUIDE.md) | The curriculum: what to use agents for, eight levels with exercises and checkpoints, and a quick reference |
| [`COACH.md`](COACH.md) | Instructions that turn any capable model into your coach |
| [`PROGRESS.md`](PROGRESS.md) | Your profile and progress, so each session continues from the last |
| [`CLAUDE.md`](CLAUDE.md) | Loads the coach automatically when you open this repo in Claude Code |

## How to start

**With Claude Code (recommended):** open this repository in Claude Code and say "let's start". `CLAUDE.md` loads the coach instructions, and the coach updates `PROGRESS.md` as you go. Come back any time and say "continue".

**With any other model:** paste the contents of `COACH.md`, `GUIDE.md`, and `PROGRESS.md` into a new chat and say "let's start". At the end of the session, save the updated `PROGRESS.md` the model gives you.

**On your own:** read `GUIDE.md` and do the exercises in order.
